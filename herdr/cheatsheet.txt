   cmd+/          menu: chat, nvim, lazygit, hunk, … (one letter runs)
   cmd+/ c        new chat tab → pick agent: enter/c Claude (chatc) · o Copilot (chatg)
   cmd+shift+g    new worktree  (type branch: feat/xyz) → chat|git|code|terminal
   cmd+i          jump to agent waiting on you
   cmd+r          workspace picker (j/k, Enter)
   cmd+k / cmd+j  previous / next workspace
   cmd+1..9       go to tab N
   cmd+shift+c    new chatc tab (Claude)
   cmd+shift+v    new code tab (nvim .)
   cmd+g          git tab (lazygit; restarts after a crash and every 4h unseen, q closes)
   cmd+shift+r    hunk live diff on the right (again = close)
   cmd+t          new tab (plain terminal)
   ^b ?           herdr: list every binding

 ── WORKSPACES / AGENTS ────────────────────────────────────────────
   cmd+shift+i    goto picker: all agents (b = blocked only)
   ctrl+k/ctrl+j  previous / next agent (all workspaces)
   ^b shift+w     rename workspace
   cmd+shift+e    edit this repo's worktree setup commands
   cmd+/ s        restart Storybook in its tab, same port (no install/build)
   cmd+/ R        review worktree for a remote branch → review | git | code | dev…
   cmd+/ x        remove this worktree + close workspace (asks first)
   cmd+/ p        next colour for this space: project on main, own on a worktree (P = back)

 ── TABS ───────────────────────────────────────────────────────────
   cmd+shift+[ ]  previous / next tab       (also ctrl+h / ctrl+l)

 ── PANES ──────────────────────────────────────────────────────────

   cmd+w          close pane
   ctrl+alt+hjkl  move between panes
   cmd+l cmd+t    zoom pane (toggle)

 ── UI / TOOLS ─────────────────────────────────────────────────────

 ── NVIM (LazyVim) — space = leader, wait after space for a menu ───
   space space    find file           space /     search in project
   space e        file tree           space g g   lazygit
   gd             go to definition    K           type / docs
   i … esc        type … stop         :w  :q      save  quit
   :LspRestart    fix stale TypeScript errors

 ── LAZYGIT ────────────────────────────────────────────────────────
   space          stage / unstage     c           commit
   P              push                p           pull
   e              edit file in nvim   ?           all keys     q quit

 ── HUNK (review diffs) ─────────────────────────────────────────────
   cmd+shift+r       side pane: live diff while Claude edits (again or q = close)
   hunk diff --watch same thing, run by hand in any pane
   cmd+/ b           right pane: everything this branch changed vs main
                     (r and b share one pane: same key closes, other swaps)
   { / }             previous / next note
   then ask Claude:  "walk me through this change in hunk"

   notes are kept:   saved every 15s, back when the pane reopens or restarts (over 700 MB)
   cmd+/ n           clear this worktree's hunk notes, saved ones too (asks first)

   ctrl+t         fuzzy pick a file path into the command
   in the list:   type to filter · arrows or ctrl+n/ctrl+p move · Enter picks
